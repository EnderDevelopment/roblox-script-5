# Roblox Scripts

This project contains a collection of Roblox Studio scripts written in Luau. Each script is designed to perform a specific function within the Roblox environment, including player movement, NPC behavior, game management, UI handling, and sound management.

## Install

1. Clone the repository to your local machine.
2. Open Roblox Studio.
3. Navigate to the desired location in your Roblox project.
4. Drag and drop the scripts into the appropriate folders.

## Use

Each script is designed to be modular and can be used independently or in combination with other scripts. Refer to the comments within each script for detailed usage instructions.
